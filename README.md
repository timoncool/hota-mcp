# hota-mcp

Исследовательский MCP-мост к установленной Heroes III + HotA + HD Mod. Данные читаются без OCR/скриншотов; нативные команды должны выполнять обычные действия игры с правами назначенного игрока. Продуктовый стек — C#/.NET и C++ x86, без Python.

**Незавершённая экспериментальная сборка.** Проверены MCP-наблюдение, частичные видимые цели/маршруты и системные опции. Нативный опыт построил рынок с обычным списанием ресурсов. После переходов игра завершалась; причина ещё расследуется. Полная игра, восстановление, все меню, бои и установщик не готовы.

- `src/HotaMcp/` — сервер, stdio/HTTP и адаптер чтения.
- `native/launcher/` — вкладка существующего HD Launcher и управление сервисом.
- `native/game/` — экспериментальный модуль игровых команд; не готов к обычным партиям.
- `tests/` — MCP smoke/lifecycle; `prototype/` — исторические исследовательские пробники.

Конечная поставка — дополнение-установщик поверх GOG Complete + HotA + HD Mod. Пользователь просит сыграть; агент сам запускает лаунчер/игру и настраивает договорённую партию. Справка и инструкции входят в дистрибутив и выдаются MCP по запросу. До независимого теста DeepSeek Flash основной агент должен пройти полную карту.

Исходники игры, игровые бинарники, сохранения и ключи не хранятся в репозитории. Адаптер привязан к проверенным хешам; поддержка других сборок требует проверки.
