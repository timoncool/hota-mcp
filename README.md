# hota-mcp

Исследовательский мост к Heroes III: Horn of the Abyss для управления игрой языковыми агентами через MCP. Наблюдения из игровых данных без OCR и скриншотов; действия через штатный ввод; информация ограничивается правами игрока.

**Статус:** работающий ограниченный MCP-прототип на C#/.NET с официальным SDK 2.2.0. Подтверждены чтение собственных показателей и открытие/закрытие системных опций через сообщения мыши по координатам структур UI. Полное управление игрой ещё не реализовано.

Нативная C++-вкладка MCP подключена к существующему HD Launcher 5.8 R18. Кнопки запускают и останавливают сервер; состояние читается через локальный named pipe. Проверен MCP-клиент через stdio-адаптер к серверу, запущенному лаунчером. Автозапуск и установщик ещё не реализованы. Актуальная контрольная точка — раздел 20 ТЗ. Конечная поставка: установщик дополнения поверх GOG Complete + HotA + HD Mod, без Python и без отдельного нового игрового лаунчера.

Цели: агент против агента с разными API, человек против агента, союзник, временная передача управления, программный hotseat и в дальнейшем проверенная работа в LAN.

## Документы и код

- [Единое ТЗ](TZ.md) — требования, архитектурные гипотезы, результаты и этапы.
- `prototype/` — экспериментальные Python-пробники для Windows и исследованной сборки HotA.
- `evidence/` — технические результаты проведённых опытов; не контракт наблюдений игрового агента.
- `native/launcher/` — C++ x86-модуль вкладки и программа подключения к исследованному лаунчеру.

Игра устанавливается отдельно. Игровые бинарники, сохранения и ключи API в репозитории не хранятся. Пробники используют адреса исследованной сборки: не запускать ввод вслепую на другой версии. До доступа игрового агента необходимы проверка сборки, фильтр прав и защищённый интерфейс команд.

Разработка и изменения ТЗ сохраняются осмысленными коммитами. Сторонние исходники H3API не включены; ссылка и исследованный commit указаны в ТЗ. Режим дизассемблирования старого пробника требует отдельно установленного `capstone`; обычные чтение UI и проверенный ввод используют стандартную библиотеку Python.
