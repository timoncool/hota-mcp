Статусы: [x] проверено; [ ] не завершено. Исследовательская реализация не равна приёмке. Актуальное состояние — STATE.md.

## Поручение пользователя 22.09.2026 — по порядку

Идут по одной, игра параллельно. Хотсит — план, делается после того, как карта пройдена и игра
размечена целиком.

1. [ ] **Отчёт хода в чат пользователю** — единый формат, три уровня подробности: одна строка
   (день, что построено/нанято, куда шли, бой и итог), средний (по героям и городу), полный (с
   причинами решений). Пишется после каждого `turn:end`.
2. [ ] **Учёт токенов на партию** — для каждой стороны: вход, выход, кеш, число вызовов, по ходам;
   журнал в каталоге сессии, сводка на конец партии. Для своей стороны — из данных харнеса, для
   агента через API — из поля `usage` ответа.
3. [ ] **`debug_snapshot` доработать** — кадр + наблюдение + полный probe контролов одним вызовом и
   работа на неразмеченных экранах (сейчас отказывает там, где разметка нужнее всего).
4. [ ] **Универсальность ввода** — где у действия есть хоткей игры, жать хоткей; кнопки опознавать
   по картинке (`UiAssets`), а не по номеру контрола; всё наружу — понятными именами.
5. [ ] **Дефекты, найденные в партии 3** — покупка из форта отвечает `uncertain`, хотя деньги
   списаны и войска в гарнизоне; план прошлой партии переживает новую; счётчик «топтания» тикает
   в меню; на панели участников не сказано, кто человек, кто компьютер и что сейчас выбрано.
6. [ ] **База знаний** — дополнять по мере игры, недостающее искать в сети; вопросы о правилах —
   в справочник MCP, а не по памяти.
7. [ ] **Пройти «Лицом к лицу» на самой лёгкой сложности до победы** (ТЗ §22) — идёт.
8. [ ] **Разметить игру целиком** — все экраны и их состояния через `debug_snapshot`.
9. [ ] **Хотсит: Claude против DeepSeek** — контроллер двух сторон на компьютере пользователя,
   раздельная память сторон, DeepSeek по официальному API (токен даст пользователь, когда готово).
10. [ ] **Игровой чат между агентами** — писать в чат игры и читать сообщения соперника.

### Открытые дефекты моста (партия 3, 22.09.2026)

- [ ] Мост не говорит, есть ли на карте подземный уровень (у игрока это кнопка-переключатель у значка замка).
- [ ] Объекты HotA на карте без имени: «объект типа 142» (Склад Золота), «банк существ №27» (Чёрная Башня), «Жилище существ 1», «Артефакт» без названия.
- [ ] Все маршруты `nearby_targets` — `not_available`, пока над картой нет настоящего курсора.
- [ ] На экране повышения выбранный навык не отмечается; в сводку не попадает строка «уровень N, атака +1».
- [ ] Экран карточки героя: слоты надетых артефактов не названы, нет сводки словами.
- [ ] `inspect_cell` меняет ревизию — каждый осмотр требует свежего `observe`.
- [ ] Катапульта в осаде не размечена.

Правило на всё: никаких автоциклов, автоходов и автоматизации за агента.
