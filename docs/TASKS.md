## Сейчас: партия вдвоём (поручение 23.09.2026)

Следующая партия — хотсит, пользователь и агент союзники против двух-трёх компьютеров на карте
крупнее. Пользователь играет своим цветом руками, агент — своим через мост. Для этого:

1. [ ] **Союзник в наблюдении** — герои и города союзника не «чужие», по ним нет тревоги; команды
   читаются из игры.
2. [ ] **Сторона службы** — за какой цвет играет мост, задаётся при запуске, а не зашито «красный».
3. [ ] **Передача хода в хотсите** — сообщение «ход игрока …» между людьми; мост действует только
   в свой ход и не жмёт за союзника.
4. [ ] **Настройка партии через мост живьём** — многопользовательская игра → хотсит → карта/случайная
   карта крупнее → два человека в одной команде, компьютеры в другой → старт. Экран настройки
   реализован (строки игроков, города, герои, бонусы, сложность, команды, случайная карта), в
   хотсите не проверен.
5. [ ] **Учёт токенов на партию** — по каждой стороне: вход, выход, кэш, число вызовов, по дням
   игры; итог на конец партии. Для Claude — из журнала харнеса, для агента по API — из поля `usage`.
6. [ ] **Отчёт хода в чат** после каждого своего `turn:end` (одна строка + детали по запросу).
