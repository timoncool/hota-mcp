# Корпус знаний агента (docs/knowledge)

Карта корпуса: что где лежит, откуда взято и по каким правилам собирается.

## Слои корпуса
| Раздел | Что это | Источник |
| --- | --- | --- |
| `knowledge/manual/h3-manual-1999-en.md` | официальный мануал Heroes III (Complete) | Steam-версия мануала, текстовый слой |
| `knowledge/manual/h3-help-ru-hlp-extract.md` | официальная справка игры (русская) | файл справки `HEROES3.HLP` из установки игры |
| `knowledge/hota/00-official-documentation.md` | официальная документация HotA: что дополнение добавляет и меняет | h3hota.com/en/documentation |
| `knowledge/core/*.md` | выжимка правил для агента: календарь и ходы, движение и местность, города и ресурсы, герои и армия, порядок боя | сделана по мануалу и справке |
| `knowledge/playbooks/*.md` | пошаговые сценарии работы через наш мост: цикл сохранения/загрузки, город и экономика, открытие хода | проверено живьём на игре |
| `knowledge/controls-hotkeys.md` | горячие клавиши и механики управления (карта, город, бой), передача армии, улучшение существ | раздел Keyboard Shortcuts мануала + раздел Town Garrison |
| `knowledge/agent/*.md` | материалы для самого агента: как играть через мост, игровой цикл, список инструментов | репозиторий и живая MCP-поверхность |

## Правила корпуса
1. Только официальная документация плюс то, что нужно самому агенту для работы. Никаких секретов, профессиональных игровых механик и супер-тонкостей: если агенту этого мало, он может поискать информацию сам.
2. Каждый файл начинается с источника и даты получения (YAML-заголовок или блок-цитата с полями `type`, `layer`, `source`, `updated`).
3. Навигация: [llms.txt](llms.txt) — корневой индекс корпуса, [DESIGN.md](DESIGN.md) — дизайн корпуса и практики, на которые он опирается, `README.md` в каждой ветке — оглавление ветки (генерируется).
4. Отдельно от корпуса лежат рабочие документы разработки: `docs/STATE.md`, `docs/CAPABILITIES.md`, `docs/LESSONS.md`, `docs/DAILY-REPORT.md`, `docs/HANDOFF-DEEPSEEK.md`.
5. Корпус читается агентом через сам мост: инструменты `hota_docs` (поиск), `hota_docs_catalog` (что вообще есть), `hota_docs_read` (прочитать файл или раздел), и ресурсы `hota://docs/index`, `hota://docs/{path}`.
6. Обслуживание: `python build/gen-docs-nav.py` (индексы, llms.txt, разбивка справки), `python build/gen-tools-doc.py` (список инструментов из живого MCP), `python build/check-docs.py` (линтер), `python build/fix-docs.py` (нормализация метаданных).
7. Индекс перечитывается мостом автоматически (кэш 10 секунд), пересборка нужна только при изменении кода `DocsIndex`.
