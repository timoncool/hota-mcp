# Передача

Контроллер блокирует новые agent actions, доводит выполняемую операцию до безопасной точки или помечает её uncertain, затем отдаёт человеку фактическое наблюдение. При возврате агенту требуется новая revision и новый decision context; старый план не исполняется автоматически.

В hotseat каждая сторона получает отдельную историю наблюдений, план и agent identity. Перед передачей проверяются current player, expected input и экран handoff. Никакие данные следующей стороны не попадают в предыдущий контекст. В LAN дополнительно нужны проверенные сетевые синхронизация, сохранение/загрузка и reconnect; это не доказано.

Текущие `GameTools.cs` не содержат handoff, pause, side selection, hotseat или LAN tools. Это целевая архитектура из TZ, а не готовая функция. `game_status` должен честно сообщать отсутствие capability.

## Модель ролей

Контроллер, а не модель, назначает сторону и разрешение команд. Человек может прервать агента; комментарий привязывается к адресату и не становится скрытой информацией другим сторонам. VCMI multi-client/server architecture полезна как концептуальный источник разделения, но не доказывает подключение HotA.
