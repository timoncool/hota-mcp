# Назначение

Короткая справка для агента, играющего через HotA MCP. Здесь собраны устойчивые различия HotA и Heroes III Complete, правила, которые влияют на решения, и ограничения версии. Это справочный слой: он не подмешивается автоматически в игровые наблюдения.

## Правило версии

Установленная игра подтверждена после перезапуска в главном меню: UI ID3001 прочитал `Версия HotA: 1.8.0`. Онлайн-страница отдельно указывает 1.8.1. Хеши установки и правила 1.8.1 не следует приписывать локальной игре.
