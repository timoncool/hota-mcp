# Стоит ли драться: как оценить силу вражеского отряда до боя

Этот файл отвечает на вопрос «выстоит ли моя армия против этого отряда» числами, которые игра
считает внутри себя, но не показывает: AI Value, Fight Value и сила армии с множителем героя.

## Что такое AI Value и Fight Value (AI value / Fight value)

Это два разных скрытых («hidden») числовых параметра существа, зашитых в движок игры. Игра нигде не показывает их напрямую игроку — оба выводятся реверс-инжинирингом сообщества.

- **AI Value** — используется для подсчёта суммарной силы армии (Army Strength). Именно AI Value суммируется при работе навыка Дипломатия (Diplomacy) и при подсчёте того, сколько опыта даёт существо при принесении в жертву на Алтаре Жертвоприношений (Altar of Sacrifice): опыт = 12.5% от AI Value существа.
- **Fight Value** — используется внутри самого боя: по нему ИИ считает Stack Value (см. ниже) и решает, какой вражеский отряд атаковать в первую очередь (приоритет цели, после скорости). Тем же Fight Value считаются потери при прохождении Воронки (Whirlpool) без соответствующего артефакта.
- AI Value и Fight Value у одного существа обычно близки, но не равны. Примеры (по данным thelazy.net):

| Существо / Creature | AI Value | Fight Value |
|---|---|---|
| Peasant / Крестьянин | 15 | 15 |
| Crystal Dragon / Кристальный дракон | 39 338 | 30 260 |
| Azure Dragon / Лазурный дракон | 78 845 | 56 315 |

Оба значения подбирались разработчиками вручную («gut feel/guess-and-check»), а не выводились по единой формуле — то есть точного вывода «почему у существа X такое-то число» нет, это откалиброванная вручную константа.

HotA правит эти числа точечно под конкретные существа (пример из changelog HotA: Fight Value ящеролюдов/Lizardmen выставлен в 115) — общий механизм (AI Value / Fight Value / формулы ниже) при этом не меняется, меняются только числа отдельных юнитов.

## Формула силы армии игрока (Army Strength, Hero strength multiplier)

Сила армии нейтрального отряда (Army Strength нейтралов) = сумма AI Value всех существ в отряде. Никакого множителя героя тут нет — у нейтралов «героя» нет.

Сила армии игрока считается иначе — с множителем от героя:

```
ASp = H × (сумма AI Value существ в армии игрока)
H = √(1 + 0.05 × A) × (1 + 0.05 × D)
```

где A — значение Атаки (Attack) героя, D — значение Защиты (Defense) героя (первичные навыки, с учётом бонусов от артефактов и вторичных навыков, которые в них конвертируются).

Практический смысл: каждая единица Атаки/Защиты у героя увеличивает эффективную силу ВСЕЙ армии (мультипликативно), а не только урон/защиту в бою — именно этот множитель H и есть числовой ответ на вопрос «насколько мой герой усиливает армию» при сравнении с нейтралами.

Официального порогового значения «ASp / (Army Strength нейтралов) ≥ X — можно атаковать» игра не публикует и в открытых источниках такого общепринятого числа не встречается (см. раздел «Пробелы»).

Источник: https://heroes.thelazy.net/index.php/Army_strength

## Формула Stack Value — как ИИ в бою выбирает цель для атаки (Stack Value, SV)

Внутри самого боя, уже после того как бой начался, ИИ каждый ход пересчитывает «ценность» каждого вражеского отряда (Stack Value, SV), чтобы решить, кого атаковать. Формула:

```
SV = (Total HP / HP) × √Sf × ASf × Df × DSf × SGf × Af × (BA × 0.05 + 1) × (BD × 0.05 + 1) × FV
```

где:
- `Total HP / HP` — сколько существ осталось в отряде относительно HP одной единицы (то есть фактически — численность отряда);
- `Sf`, `ASf` — множители от щита/воздушного щита (Shield/Air Shield) на отряде;
- `Df` — множитель урона отряда;
- `DSf` — множитель двойного выстрела (Double Shot): 2, если у существа есть эта способность (например, у стрелков с двойным выстрелом), иначе 1;
- `SGf` — множитель окаменяющего взгляда (Stone Gaze): 0.5, если способность активна на цели;
- `Af` — множитель брони/защиты цели;
- `BA`, `BD` — бонусная Атака/Защита от заклинаний и умений героя (каждая единица даёт +5% множителя);
- `FV` — базовый Fight Value существа (см. выше).

Это формула для внутрибоевого таргетинга ИИ, а не формула «довоенной» оценки шансов — но она прямо показывает, ЧТО из перечисленного в задании реально влияет на боевую ценность отряда изнутри движка: двойной выстрел (х2), окаменение (х0.5), щиты, бонусные атака/защита от заклинаний героя. Явного отдельного множителя на «скорость» в этой формуле нет — скорость учитывается раньше, при определении порядка ходов, а не в SV.

Источник: https://heroes.thelazy.net/index.php/AI_value

## Сколько отрядов будет в бою — деление нейтрального стека (Number of stacks, split by relative strength)

Нейтральный «пак» на карте приключений в бою делится на несколько отдельных отрядов (стеков). Количество этих отрядов зависит от того, насколько армия игрока сильнее или слабее нейтралов (по соотношению Army Strength):

| Относительная сила атакующего героя к нейтралам | Число отрядов в бою |
|---|---|
| < 50% | 6–7 |
| 50%–<67% | 5–7 |
| 67%–<100% | 4–6 |
| 100%–<150% | 3–5 |
| 150%–<200% | 2–4 |
| ≥ 200% | 1–3 |

Внутри диапазона есть небольшой разброс (не случайный): конкретная клетка карты приключений (её координаты) сдвигает число отрядов на ±1.

Практический вывод: чем сильнее игрок относительно нейтралов, тем МЕНЬШЕ отдельных отрядов будет в бою (и тем легче их выцеливать/фокусировать по одному), а не только «тем легче в целом».

Источник: https://homm.miraheze.org/wiki/Wandering_creature

## Как игра словами оценивает численность нейтрального отряда (Population estimate words / troop stack size labels)

Пока у героя нет способа увидеть точное число (см. следующий раздел), на карте приключений при наведении на нейтральный отряд игра показывает не число, а слово-оценку. Точные диапазоны, стоящие за словами:

| Слово (RU, принятый перевод) | Слово (EN) | Диапазон численности |
|---|---|---|
| Мало / несколько | Few | 1–4 |
| Несколько | Several | 5–9 |
| Отряд / стая | Pack | 10–19 |
| Много | Lots | 20–49 |
| Орда | Horde | 50–99 |
| Толпа | Throng | 100–249 |
| Стая (рой) | Swarm | 250–499 |
| Тьма | Zounds | 500–999 |
| Легион | Legion | ≥ 1000 |

(Русские названия слов-оценок в самой GOG-версии могут отличаться формулировкой от таблицы выше — сами диапазоны чисел от локализации не зависят и не проверялись отдельно по русской версии клиента, см. «Пробелы».)

## Что даёт навык Разведка (Scouting) — и чего НЕ даёт

Разведка (Scouting) увеличивает только радиус обзора героя на карте приключений (сколько клеток вокруг героя видно), она НЕ уточняет численность нейтрального отряда и не превращает словесную оценку («орда», «легион» и т.д.) в точное число.

| Уровень | SoD / Complete | HotA |
|---|---|---|
| Базовый (Basic) | +1 клетка к радиусу обзора | +1 клетка (без изменений) |
| Продвинутый (Advanced) | +2 клетки | +3 клетки |
| Экспертный (Expert) | +3 клетки | +5 клеток |

В HotA 1.8.x радиус обзора от Разведки увеличен на продвинутом и экспертном уровне (было +2/+3, стало +3/+5); базовый уровень не менялся.

Источник: WebSearch-агрегация по https://heroes.thelazy.net/index.php/Scouting , https://homm.fandom.com/wiki/Scouting , https://homm.miraheze.org/wiki/Scouting (точный URL конкретной формулировки HotA-патчноута не зафиксирован, см. «Пробелы»)

## Что реально даёт точное число: заклинание Visions и существо Разбойник (Rogue)

Без специальных условий игрок НЕ видит точное число существ в нейтральном отряде или в армии другого героя — только слово-оценку из таблицы выше. Точное число открывают:

- **Заклинание Visions** (2-й уровень магии, школа — любая; в русской локализации точное имя не проверялось, возможные варианты — «Видения»/«Прозрение», см. «Пробелы»). Стоимость — 4 маны и 2 очка передвижения, действует 1 день (сутки).
  - Базовый уровень (Basic): показывает точное число существ в нейтральном отряде и то, предложит ли он присоединиться. Радиус действия = Сила магии героя (Power/Spell Power), но не меньше 3 клеток.
  - Продвинутый (Advanced): то же плюс первичные характеристики вражеского героя и точный состав/численность его армии. Радиус = Power × 2 (не меньше 3).
  - Экспертный (Expert): то же плюс статистика вражеского города и точный состав/численность гарнизона. Радиус = Power × 3 (не меньше 3).
- **Существо Разбойник (Rogue)** в армии героя: пока в армии есть хотя бы один Разбойник, для этого героя действует эффект, равный экспертному Visions, — постоянно, без траты маны. Эффект пропадает, если Разбойники погибнут или будут переданы другому герою.

Источник: https://homm.fandom.com/wiki/Rogue (через WebSearch-агрегацию, прямой fetch недоступен — см. «Пробелы»)

## Когда нейтралы не станут драться

Перед боем отряд сравнивает «харизму» героя со своим настроением и может предложить присоединиться, сторговаться за золото или убежать. Механика присоединения, влияние Дипломатии и правка HotA «только за деньги, 50%» — [найм героев и присоединение нейтралов](../rules/hiring-and-diplomacy.md).

## Отступление и сдача

Отступление бесплатно и всегда удаётся, но армия теряется целиком; сдача возможна только против героя, стоит золота и армию сохраняет. Цены, ограничения, скидки Дипломатии и правки HotA — [боевая математика](../rules/combat.md), раздел «Сколько стоит отступление и сдача».

## Скорость и способности как приём против сильных отрядов (kiting)

Отдельный практический приём для боя с нейтральным отрядом, который «на бумаге» сильнее армии игрока: если существо игрока не получает ответный удар (no retaliation) и заметно быстрее противника, можно бить и отходить, не неся потерь.

- Порог по игре: скорость своего существа должна быть больше чем в 2 раза выше скорости противника, ИЛИ скорость противника ≤ 4 (тогда почти любое существо игрока успевает уйти).
- Ускорить/замедлить это соотношение можно заклинаниями Haste (на себя) / Slow (на противника).
- Годятся существа без ответного удара: Harpy Hag (Гарпия-ведьма — единственная, кто после удара возвращается на исходную клетку), Cerberus/Церберы, Archdevil/Архидьяволы, Sprite/Феи, Vampire Lord/Лорд-вампир и т.п.
- Осторожно с Моралью (Morale) у противника — лишний ход нейтралов может сломать тайминг приёма.

Источник: https://heroes.thelazy.net/index.php/Tricks
