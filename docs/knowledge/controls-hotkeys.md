## Передвижение по карте (курсоры)
- Клик по клетке, где показан значок движения, строит маршрут от текущего героя до клетки; в правом нижнем углу видно, за сколько ходов герой дойдёт (0 = сегодня).
- Курсор меняется: походный/полётный/атака. Значок «атаки» (меч) показывается на блуждающих монстрах, вражеских городах, вражеских гарнизонах и вражеских героях.

## Блуждающие монстры (оценка опасности)
- **ПКМ по блуждающему отряду** показывает тип существ и грубую оценку численности (это штатный способ игры узнать, что там стоит).
- Оценка численности словами: Few 1–4, Several 5–9, Pack 10–19, Lots 20–49, Horde 50–99, Throng 100–249, Swarm 250–499, Zounds 500–999, Legion 1000+.
- У отряда есть «враждебность» 1–10: чем выше, тем охотнее нападает; отряды избегают боя с армией сильнее себя.

## Гарнизон города и герой-гость
- Когда герой в городе, его войска можно обменивать с гарнизоном.
- Чтобы герой возглавил гарнизон: **кликнуть по портрету героя (подсветить), затем кликнуть по знамени слева от первого слота гарнизона** — армии объединяются, герой встаёт во главе обороны города.
- Поменять гостящего и гарнизонного героев (вместе с армиями): подсветить одного и кликнуть по другому.
- **Вернуть героя из гарнизона на карту: клик по портрету героя (выбрать), затем клик по СТРОКЕ НИЖЕ (ряд армии).** Проверено на живой игре. Перетаскивание (drag) игра в этом месте не распознаёт — открывается экран героя. В мосте: действие `hero:out` (op 63).
- Улучшение существ: **двойной клик по отряду** открывает карточку существа, кнопка Upgrade показывает цену (разница цен найма × число существ), подтверждение — «галочка».
- Отряды в гарнизоне можно перемещать, разделять, объединять и распускать.

## Кэш маршрутов и реальный курсор (проверено 20.09.2026)
Игра строит кэш маршрутов («докуда герой дойдёт сегодня») **от реального положения курсора мыши над окном игры**. Пока настоящий курсор вне окна (человек печатает в чате, окно не под курсором), кэш не строится, и чтение маршрутов отдаёт «недоступно» с причиной вида «The game has not extended its route cache to (x,y)». Синтетический ховер оконными сообщениями кэш не строит (клики при этом работают). Для постановки маршрута игре нужен настоящий курсор над картой.

## Практические выводы для моста
1. `H` используется как «выбрать героя» (op 54), `M` — как «идти по маршруту» (op 31/34), `E` — конец хода (op 28). Это штатные клавиши игры, а не эмуляция.
2. Экран города: Space — переключение гостящий/гарнизонный герой; знамя слева от гарнизона — объединение армий; двойной клик по отряду — карточка существа (upgrade).
3. Одиночный клик по отряду — «взять отряд» (он следует за курсором), клик по целевому слоту — положить. Два клика подряд быстрее ~0.5 с игра считает двойным кликом и открывает карточку существа (это уже наблюдалось).
4. Опасность на карте оценивается штатной справкой: ПКМ по монстрам (тип + грубая численность), состояние маршрута (`reachable_today`), плюс признаки курсора (атака/движение).
