# Черновик

Агент играет только назначенную сторону и видит только данные, возвращённые MCP для этой стороны. Правила и справка вызываются отдельно; не считать `observe` энциклопедией или советчиком.

## Capability discovery

В начале сессии вызвать `game_status`, затем `observe`. Использовать только перечисленные в ответе capabilities и фактически зарегистрированные tools. Список инструментов берётся из discovery, а не из этого файла: он меняется быстрее документации. На момент правки мост даёт наблюдение (`observe`, `nearby_targets`, `inspect_target`, `read_map`), осмотр как у игрока (`inspect_cell`, `inspect_element`), движение (`move_to`, `move_to_tile`, `attack_target`), действия экранов (`act`, `click_ui`), справку (`hota_docs`, `hota_docs_catalog`, `hota_docs_read`, `hota_reference`) и служебное (`game_status`, `plan`, `read_journal`, `debug_snapshot`). Не выдумывать имена, которых нет в discovery.

## Основной цикл

1. Получить observation и сохранить revision.
2. Выявить обязательный экран/диалог и одну ближайшую цель.
3. Запросить отдельную справку по неизвестному правилу, если она нужна для решения.
4. Сформировать короткий plan с целью, предпосылками и uncertainty.
5. Выполнить только разрешённое действие с ожидаемой revision и operationId.
6. Наблюдать результат, обновить plan и продолжать самостоятельно до выполнения цели или до причины остановки, требующей пользователя. Новая развилка означает новое решение и свежий observation, а не завершение работы.

Это LLM-адаптация формы Nullkiller2 (analyzers/goals/tasks), а не копия VCMI AI и не стратегическая рекомендация из моста.

## Stale и uncertain

- Если revision изменилась до отправки — отбросить команду, заново `observe`.
- Если target ID исчез или стал недоступен — не угадывать координату/новый ID; запросить свежие видимые цели.
- Если action timeout/ошибка неясна — не повторять с новым operationId. Сначала `observe`, затем `read_journal`; повторять только исходный operationId, если контракт явно допускает retry.
- Если экран/сторона/право управления не подтверждены — остановиться и сообщить причину.
- Если поле недоступно, вернуть uncertainty/unknown в плане, не выводить его из скрытой памяти или VCMI-правил.

## Что агент не делает

Не читает сырые адреса, скрытые клетки, чужую память, полное сохранение; не меняет ресурсы/координаты напрямую; не выдаёт VCMI capability за HotA; не зашивает советы в `observe`; не объявляет полную игру поддержанной при отсутствии tools для города, движения, боя и конца хода.
