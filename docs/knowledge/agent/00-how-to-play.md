# Как играть в Heroes III через этот мост (памятка агенту)
> **type:** reference · **layer:** agent · **source:** Материалы для агента · **updated:** 2026-09-20


Короткая сводка для агента, который садится играть: с чего начать сессию, как выглядит игровой день, что важно помнить. Подробности — в `knowledge/playbooks/*` и `knowledge/core/*`.

## Начало сессии
1. `game_status` — узнать, привязан ли мост к живой игре; при необходимости `start_game`.
2. `observe` — получить состояние: текущий экран, дата (месяц, неделя, день), ресурсы, свой герой и его армия, доступные действия. Все действия требуют `revision` из последнего наблюдения.
3. Если экран не `adventure` (открыт город, диалог, бой) — сначала вернуться на карту приключений доступным действием (`town:close`, `message:accept`, `split:cancel`).
4. Если герой не выбран, а он на карте — действие `hero:select` (штатная клавиша H).

## Игровой день
1. Открыть город (`town:open:<n>`) и посмотреть, что можно построить и нанять (`town:construction`, `building:inspect:<слот>`, `building:buy`; `town:recruit:<уровень>`, `recruit:max`, `recruit:buy`).
2. Провести армию герою: в городе герой-гость соединяет свою армию с гарнизоном (`town:lead`: портрет, затем знамя). Найм при герое вне города попадает в гарнизон.
3. Идти героем по карте, пока есть движение: `nearby_targets` (что рядом), `move_to:<цель>` (к объекту), `move_to_tile:<x,y,z>` (в произвольную клетку, для разведки). Движение — ресурс: свободных ходов не оставлять.
4. Собирать ресурсы и посещать объекты (`message:accept` для диалогов), избегать лишних боёв: команда на клетку монстра означает атаку.
5. Закончить ход: `turn:end` и подтвердить вопрос о конце хода.

## Игровой цикл и сроки
- День — один ход игрока; неделя — 7 дней; месяц — 4 недели. В первый день недели приходит прирост существ в жилищах, в первый день месяца — небольшой прирост ресурсов.
- Доход города капает каждый день; постройки усиливают доход и рост существ. Логичная лестница: Рынок/Кузница → Муниципалитет (2000/день) → Цитадель (+50% роста) → Замок (рост ×2) → Капитолий (4000/день).
- Движение героя восстанавливается каждый день; герой с армией сильнее, чем герой без армии, но бой — это потеря существ, поэтому выгоднее сначала собрать армию, потом воевать.
- Нанятый в таверне герой приходит с армией; после поражения героя выгоднее купить нового, чем тянуть старого без армии.

## Опасность на карте
- Блуждающие монстры стоят на клетках: команда на такую клетку = атака, путь «мимо» игра останавливает сама.
- Оценить отряд можно справкой игры (ПКМ по монстру: тип и грубая численность — Few/1–4, Several/5–9, Pack/10–19, Lots/20–49, Horde/50–99, Throng/100–249, Swarm/250–499, Zounds/500–999, Legion/1000+).
- Доступность маршрута видна по состоянию цели (`reachable_today` / `not_available`); недостижимая цель — это не ошибка моста, а решение игры.

## Дисциплина работы
- Одно действие — один `operationId`; при `uncertain` наблюдать заново, а не повторять под новым ID.
- После каждого проверенного игрового факта писать в `docs/LESSONS.md`, а покрытие инструментов отмечать в `docs/CAPABILITIES.md`.
- Скриншоты — только для разработки нового пути; боевая игра идёт по семантике наблюдений.
